# Claude skills

40 skills for Claude Code, adapted from [Hermes Agent](https://github.com/NousResearch/hermes-agent) by Nous Research (MIT licence, see `LICENSE-hermes-agent`).

Start a Claude Code session from this repo and the skills in `.claude/skills/` load automatically.
To use them on your own computer, copy the folders into `~/.claude/skills/`.
