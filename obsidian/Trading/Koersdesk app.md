# Koersdesk

My own free crypto app (Windows). Download the latest installer:
https://github.com/efekan3/claude-skills/raw/downloads/

Source code: https://github.com/efekan3/claude-skills/tree/main/apps/crypto-desk

| Tab | What it's for |
|---|---|
| Markets | Live prices (Bitvavo euros), watchlist ★, top movers |
| Chart | Live candles, EMA, Bollinger, RSI/MACD, order book, trades |
| News | Headlines from CoinDesk, Decrypt, Cointelegraph |
| Insights | Trend, scenarios, reactions to past events, similar setups |
| Practice | Trade virtual €10,000 with a live chart → log in [[Trade journal entry]] |
| Bot | Paper-trading bot → weekly [[Bot check-in]] |
| Coach | The 10 lessons (also in this vault), quizzes, strategy lab, chat coach |

**Back up:** Practice → *Back up all data*. Keep the file next to this vault.
